# FTC 跑打算法工程笔记：基于线性组合气动力模型的精确弹道解算

## 一、背景与问题定义

FTC 比赛中，利用发射机构将小球射入目标区域是常见的得分手段。然而，小球在飞行过程中受到重力、空气阻力、升力、马格努斯效应等多种气动力的共同作用，使得弹道呈现出复杂的非线性特征。

传统方案存在明显局限：

| 方案 | 精度 | 标定成本 | 实时性 |
|------|------|----------|--------|----------|
| **线性回归**（常见于 FTC 队伍） | 低 | 低 | 高 |
| **查表法**（强队常用） | 高 | **极高**（需采集数百组数据） | 高 |
| **CFD 仿真** | 理论上最高 | **不可行**（算力要求极高） | — |

我们的目标是：**在保证实时性的前提下，用可接受的标定成本，获得远超线性回归的弹道精度**。

## 二、核心创新：线性组合气动力模型

### 2.1 物理直觉

抛射体在空中受到的气动力种类繁多：压差阻力、摩擦阻力、诱导阻力、马格努斯升力、尾流升力……它们的合力方向不一定沿速度反方向，也不一定垂直向上。但是，我们事实上不关心“具体是哪种力在起作用”，只关心“**合力**在轨迹平面内的表现”。因此，我们选择**绕过复杂的流体力学建模，直接模拟气动力合力**

### 2.2 数学建模

在**无风条件**下：有一个关键观察：

 **所有气动力的合力必定位于小球速度矢量 $\mathbf{v}$ 与竖直方向单位向量 $\mathbf{z}$ 所张成的轨迹平面内。**

这是因为抛体运动本身被约束在由初速度和重力方向决定的平面内，而小球自身的气动力（无论来源如何）作用于小球上，其合力不会将小球推出这个平面。

由线性代数基本定理，轨迹平面内的任意向量可表示为 $\mathbf{v}$ 与 $\mathbf{z}$ 的线性组合。在此基础上，假设每个气动力都与速度**近似正比**，气动力合力就可简洁地写作：

$$
\mathbf{F} = [\mathbf{v} \ |\mathbf{v}|  \mathbf{z}]\mathbf{k}
$$

其中$\mathbf{k}$为2维向量，展开为矩阵形式：

$$
\mathbf{F} = \begin{bmatrix}
v_x \ 0 \\
v_y \ 0 \\
v_z \ |\mathbf{v}|
\end{bmatrix}
\mathbf{k}
$$

对应的加速度为：

$$
\begin{cases}
a_x = -\dfrac{k_x}{m} |\mathbf{v}| v_x \\[8pt]
a_y = -\dfrac{k_x}{m} |\mathbf{v}| v_y \\[8pt]
a_z = -\dfrac{k_x}{m} |\mathbf{v}| v_z + \dfrac{k_y}{m} |\mathbf{v}| - g
\end{cases}
$$

这种建模方法不关心气动力的产生原因，因而理论上**适用任何发射场景**，具备良好泛用性。
### 2.3 核心优势
以上模型中，只需标定2个标量，极大减轻了标定难度，同时理论上又可达到接近查表法和CFD的精度，实现了“强队查表法的精度 + 普通线性回归的低标定成本”的平衡。

| 维度 | 线性回归 | 查表法 | **本方案** |
|------|----------|----------------|------------|
| 模型复杂度 | 低 | 中 | 中 |
| 标定数据量 | 3~5 组 | 100+ 组 | **5~10 组** |
| 保证精度的容许射程 | 1m以内 | 全场 | **几乎全场** |
| 能否跑打 | ✅ | ❌（通常忽略） | ✅ |
| 适用场景 | 任意 | 特定场地 | **任意** |

**核心优势总结**：

1. **物理合理性**：超参 $\mathbf{k}$ 从线性组合角度捕捉所有气动力合力，有明确的数学基础
2. **标定成本低**：仅需 5~8 组不同距离的射击数据，远低于查表法的百组级别
3. **精度高**：实测平均误差 < 0.08 m，远超线性回归
4. **实时性强**：单次求解 < 2 ms，满足 20~50 Hz 控制需求
5. **泛化能力**：同一组参数适用于不同小车速度和目标移动场景

## 三、算法核心架构

### 3.1 RK4 数值积分

采用四阶龙格-库塔法求解微分方程，步长 $\Delta t = 0.01\,\text{s}$。单次仿真步数约 40~80 步（飞行时间 0.4~0.8 秒）。

### 3.2 双层迭代求解器

外层迭代修正炮塔水平角 $\phi$，内层通过二分法搜索仰角 $\theta$ 或初速度 $v_0$。

#### 外层迭代——炮塔角修正

设地面所需速度方向为 $\psi_{\text{req}}$，机器人速度为 $\mathbf{v}_r$，则有：

$$
\phi^{(k+1)} = \psi_{\text{req}} - \arcsin\left( \frac{v_r^{\perp}}{v_0 \cos\theta^{(k)}} \right)
$$

其中 \(v_r^{\perp}\) 是机器人速度垂直于目标方向的分量。

代码实现（`Solver.java`）：

```java
private double calculatePhiCorrection(double groundAngle, double turretPhi,
                                     RobotState robotState, double vHorizontal) {
    double vRx = robotState.vx;
    double vRy = robotState.vy;
    double correction = (vRy * Math.cos(groundAngle) - vRx * Math.sin(groundAngle)) / vHorizontal;
    return correction;
}
```

#### 内层二分搜索

仰角搜索（固定 $v_0$）和初速度搜索（固定 $\theta$）均采用二分法，终止条件为落点误差 < 0.001 m 或达到最大迭代次数。

### 3.3 参数标定：两段搜索法

用最小二乘定义损失函数：

$$
\mathcal{L}(k_x, k_y) = \frac{1}{2} \sum_{i=1}^{N} \left[ D_{\text{sim}}(\theta_i; k_x, k_y) - D_i \right]^2
$$

$\mathcal{L}$ 非凸，但注意到其在最小值的一个小邻域内近似凸，故采用两段搜索：

1. **粗搜索**：\(k_x \in [-0.1, 0.1]\)，步长 0.005；\(k_y \in [-0.5, 0.5]\)，步长 0.025
2. **精搜索**：在最优邻域内以更小步长（0.001 和 0.005）再次搜索

代码实现（`CalibrationHelper.java`）：

```java
public CalibrationData fitDragParameters(double[][] v0RangeAngleData, ProjectileParameters params) {
```
